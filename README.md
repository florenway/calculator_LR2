# Калькулятор

Непрограммируемый калькулятор для Android. Два поля для чисел, знак операции между ними и поле результата. Вся разметка собрана на `GridLayout`.

Готовый подписанный APK: [`apk/calculator.apk`](apk/calculator.apk)

## Что умеет приложение

- Сложение, вычитание, умножение и деление
- При делении на ноль в поле результата выводится «Ошибка: деление на ноль»
- Нажатие на поле ввода открывает числовую клавиатуру
- Кнопки `+`, `−`, `×`, `÷` меняют знак между двумя операндами
- Кнопка «С» очищает оба поля ввода, результат и возвращает знак к «+»
- Кнопка «=» считает результат
- Отдельные макеты для портретной (`res/layout`) и альбомной (`res/layout-land`) ориентации
- На экране есть `TextView` с ФИО и группой

## Как поставить APK на телефон

Файл уже подписан (схемы v1, v2 и v3), это обычный APK, не AAB. Его можно устанавливать напрямую.

1. Скачайте `apk/calculator.apk` из репозитория (не распаковывайте его).
2. Передайте файл на телефон: USB, мессенджер или облако.
3. Откройте файл на телефоне и разрешите установку из этого источника, если система спросит.
4. Если система пишет, что приложение не удалось установить, сначала удалите уже стоящий «Калькулятор» с этой же подписью или с другой сборкой и установите файл ещё раз.

Проверка с компьютера, если установлен Android SDK:

```bash
adb install -r apk/calculator.apk
```

Минимальная версия Android — 5.0 (API 21).

## Как открыть проект

Нужны Android Studio и Android SDK (в проекте `compileSdk 35`).

1. Android Studio → Open → папка проекта.
2. Дождитесь синхронизации Gradle. Файл `local.properties` студия создаст сама.
3. Запустите конфигурацию `app` на эмуляторе или телефоне.

Сборка из командной строки:

```bash
./gradlew assembleRelease test
```

Release-сборка подписывается учебным ключом `keystore/calculator.jks` (пароль и alias: `calculator`). Готовый файл после сборки лежит в `app/build/outputs/apk/release/`. В репозиторий он дополнительно скопирован как `apk/calculator.apk`.

## Как пользоваться

1. Нажмите первое поле и введите число. Откроется числовая клавиатура. Дробь можно писать точкой или запятой, знак минус тоже принимается.
2. Нажмите `+`, `−`, `×` или `÷`. Знак между полями сменится на выбранный, кнопка подсветится.
3. Введите второе число.
4. Нажмите `=`.
5. «С» стирает оба числа и результат.
